# valley-agent

## 🚀 开发路线图与项目演化过程

### 📌 Stage 1: 感知与简单闭环（“挂机睡觉”Agent）

- 核心目标：彻底跑通 “游戏画面截取 $\rightarrow$ VLM 视觉状态提取 $\rightarrow$ Python 逻辑判定 $\rightarrow$ 自动化执行动作” 的最短最小可行性闭环。
- 预期功能：防止角色在凌晨 2:00 因超时在野外昏迷，实现了资产与生命的初步安全保障。

- 实现路径：
  1. 建立轮询机制初始化 agent。
  2. 实现游戏窗口的单次 **毫秒级** 精准切片截图更新游戏环境属性。
  3. 触发器逻辑：当 VLM 判定游戏内时间到达深夜（例如 10:00 PM 之后），状态机切换为“强制睡眠”模式，通过自动化控制指令让角色回到床边躺下。

- 验证结果：看电视查看运气和明天天气，如果是好运天则走出房子，挂机到晚上回家睡觉，如果霉运天则直接睡觉，如果是雨天则走到巴士站后回家睡觉。

### 📌 Stage 2: 经济具体化（“自动种地”Agent）

- 核心目标: 引入宏观目标拆解与游戏内资产增值逻辑。

- 预期功能：Planner 拆解用户长远目标（如“买马”），动态决策作物种植。Agent 每日起床后感知土地状态，自动执行浇水、收割、出货箱售卖等复合循环。

### 📌 Stage 3: 动态决策与多目标（“全能型”Agent）

- 核心目标：处理游戏内的混沌突发事件。

- 预期功能：感知天气和运气（下雨天或者好运天自动切换为“去矿洞刷铜矿”或“去河边钓鱼”）；引入背包满载处理与异常状态应对机制。

### 📌 Stage 4: 主线感知与分层记忆（“精英型”Agent）

- 核心目标: 构建“长-中-短”三层记忆链条与反思机制，解除 VLM 频繁调用的算力负担，使 Agent 具备处理混沌突发事件、自主多线调度以及动态修正 KPI 的高阶决策能力。
