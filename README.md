# valley-agent

## 🚀 开发路线图与项目演化过程

### 📌 Stage 1: 感知与简单闭环（“挂机睡觉”Agent）

- 核心目标：彻底跑通 “跨地图非视野内长线任务的动态空间测绘与局部避障寻路” 的最短最小可行性闭环。

- 核心功能：
  1. 宏观地图拓扑链条分解：能够将视野外的长线最终目标（如某张远端地图的特定 NPC 或设施），自动拆解为由一系列邻接地图组成的“转场节点链条”。
  2. 多模态动态空间对齐：在角色每步入一张新地图（或清晨起床时），利用 VLM 对当前屏幕图像进行一次性扫描，动态判定主角与当前阶段目的地（如出口大门或目标）的归一化像素比例位置，彻底消除截图窗口栏干扰及镜头卡边界导致的绝对坐标失效。
  3. 局部路径高频动态扫描：VLM 在定位起终点的同时，以主角为动态原点，辐射扫描视野内沿途的所有障碍物（家具、树木、机器等），将其数字化为相对网格坐标。
  4. A\* 算法寻路机制：在本地利用纯算法求解局部迷宫路径，并将其翻译为精细的键盘 WASD 物理实体按键，在走路期间完全不需要高频轮询大模型，兼顾流畅度与成本。
  5. 多目标自适应筛选交互：当到达最终地图时，系统自动结合提示词修饰符（如“最左侧”、“柜台后”），在同类多个目标中进行视觉锁定与精准物理对位交互。

- 验证结果：去皮埃尔杂货铺进行买种子交互。
- 核心指标：消耗token，轮询性能，完成任务时间。

### 📌 Stage 2: 经济具体化（“自动种地”Agent）

- 核心目标: 引入宏观目标拆解与游戏内资产增值逻辑。

- 预期功能：Planner 拆解用户长远目标（如“买马”），动态决策作物种植。Agent 每日起床后感知土地状态，自动执行浇水、收割、出货箱售卖等复合循环。

### 📌 Stage 3: 动态决策与多目标（“全能型”Agent）

- 核心目标：处理游戏内的混沌突发事件。

- 预期功能：感知天气和运气（下雨天或者好运天自动切换为“去矿洞刷铜矿”或“去河边钓鱼”）；引入背包满载处理与异常状态应对机制。

### 📌 Stage 4: 主线感知与分层记忆（“精英型”Agent）

- 核心目标: 构建“长-中-短”三层记忆链条与反思机制，解除 VLM 频繁调用的算力负担，使 Agent 具备处理混沌突发事件、自主多线调度以及动态修正 KPI 的高阶决策能力。
